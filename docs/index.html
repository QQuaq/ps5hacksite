03 — Rehber

İlk kurulum.

  1. Bilgisayarda start.bat dosyasını yönetici olarak çalıştır.
  2. PS5: Ayarlar → Ağ → İnternet Bağlantısını Kur → Gelişmiş Ayarlar.
  3. IP adresi: Otomatik. DHCP ana bilgisayar adı: Ayarlama.
  4. DNS: Manuel. Birincil: —. İkincil: 1.1.1.1.
  5. MTU: Otomatik. Proxy: Kullanma. Bağlantıyı test et.
  6. Kullanım Kılavuzu’nu aç veya tarayıcıya https://qquaq.github.io/ps5hacksite/ yaz.

HTTPS kilidi yüzünden kılavuz bazen açılmaz. O zaman doğrudan https://qquaq.github.io/ps5hacksite/ adresini kullan.
